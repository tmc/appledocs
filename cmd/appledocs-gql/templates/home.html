Apple Docs API

This API provides access to the cached Apple documentation.

GraphQL Playground Apollo Sandbox Schema Documentation

REST API Endpoints

GET /api/document

Retrieve a document by its path.

Parameters:

  • path - The path to the document (required)

Example:

GET /api/document?path=tutorials/data/documentation/swiftui

GET /api/search

Search for documents containing a specific query.

Parameters:

  • q - The search query (required)
  • limit - Maximum number of results to return (default: 10)

Example:

GET /api/search?q=SwiftUI&limit=5

GET /api/frameworks

Get a list of all available frameworks.

Example:

GET /api/frameworks

GraphQL Interface

A GraphQL-like interface is available at /graphql

GraphQL Schema

The API supports a rich GraphQL schema with various data types and queries.

View schema documentation Try in GraphQL Playground

Example queries:

# Get a document by path
{
  document(path: "tutorials/data/documentation/swiftui") {
    id
    title
    abstract
    type
    framework
    platforms {
      name
      introducedAt
    }
    isDeprecated
  }
}

# Search for documents
{
  search(query: "SwiftUI", limit: 5) {
    documents {
      id
      title
      abstract
    }
    count
    query
  }
}

# Get all frameworks
{
  frameworks {
    id
    title
    abstract
    platforms {
      name
    }
  }
}

# Get a specific framework
{
  framework(id: "swiftui") {
    id
    title
    abstract
  }
}

# Get documents by type
{
  documentsByType(type: "class", framework: "swiftui") {
    id
    title
    abstract
  }
}

# Get related documents
{
  relatedDocuments(path: "tutorials/data/documentation/swiftui", limit: 3) {
    id
    title
    abstract
  }
}
