Apple Docs API

This API provides access to Apple documentation through both REST and GraphQL interfaces.

GraphQL Playground Apollo Sandbox GraphQL Schema

REST API Endpoints

Get a document by path

GET /api/document?path=...

Retrieve a document by its path relative to the cache directory.

Example: /api/document?path=tutorials/data/documentation/swiftui

Search for documents

GET /api/search?q=...&limit=...

Search for documents containing the specified query string. Optionally limit the number of results.

Example: /api/search?q=SwiftUI&limit=5

List all frameworks

GET /api/frameworks

Get a list of all frameworks in the documentation.

Example: /api/frameworks

GraphQL API

The GraphQL API provides a more flexible way to query documentation data.

You can use the GraphQL Playground to explore and test GraphQL queries.

Example Queries

# Get a document by path
{
  document(path: "tutorials/data/documentation/swiftui") {
    id
    title
    abstract
  }
}

# Search for documents
{
  search(query: "SwiftUI", limit: 5) {
    documents {
      id
      title
      abstract
    }
    count
    query
  }
}

# List all frameworks
{
  frameworks {
    id
    title
    abstract
  }
}
