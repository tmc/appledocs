# DarwinKit-Style Template Architecture Design

## Overview

This document specifies the design for `templates_darwinkit.txtar`, a template variant that generates darwinkit-quality bindings with one file per class instead of a monolithic `classes.gen.go`.

## Goals

1. Generate one Go file per Objective-C class (e.g., `button.gen.go`, `window.gen.go`)
2. Match darwinkit's code structure and quality
3. Use objc runtime calls (`objc.Call`, `objc.Sel`, `objc.GetClass`)
4. Generate proper interface/struct/class variable patterns
5. Support class methods, instance methods, and constructors
6. Maintain compatibility with existing generator infrastructure

## File Structure

### Directory Layout

```
generated/frameworks/appkit/
├── doc.gen.go              # Package documentation
├── gen.go                  # go:generate directive
├── types.gen.go            # Type definitions (if needed)
├── functions.gen.go        # C functions (if any)
├── button.gen.go           # NSButton class
├── window.gen.go           # NSWindow class
├── view.gen.go             # NSView class
└── ...                     # One file per class
```

### Per-Class File Structure

Each class file (e.g., `button.gen.go`) contains:

1. **Package header** with generation comment
2. **Imports** (unsafe, objc, foundation, etc.)
3. **Class variable** declaration (`var ButtonClass _ButtonClass`)
4. **init() function** that calls `objc.GetClass`
5. **Private class struct** (`type _ButtonClass struct`)
6. **Public interface** (`type IButton interface`)
7. **Public struct** (`type Button struct`)
8. **Constructor wrapper** (`ButtonFrom(ptr unsafe.Pointer)`)
9. **Class methods** (factory methods, static methods)
10. **Instance methods** (all instance methods)

### ClassData (per-class context)

```go
type ClassData struct {
    // Naming
    ObjCName         string   // "NSButton"
    GoName           string   // "Button"
    FileName         string   // "button.gen.go"
    ReceiverShort    string   // "b" or "bc"

    // Hierarchy
    SuperClass       string   // "Control" (Go name)
    SuperObjCClass   string   // "NSControl"

    // Documentation
    Abstract         string   // From Apple docs
    DocURL           string   // https://developer.apple.com/...
    Availability     Availability

    // Methods (organized)
    ClassMethods     []*MethodData  // Factory methods
    InstanceMethods  []*MethodData  // Instance methods
    Properties       []*PropertyData

    // Dependencies
    NeedsFoundation  bool
    NeedsQuartzCore  bool
    ImportedTypes    []string
}
```

### MethodData (per-method context)

```go
type MethodData struct {
    // Naming
    Name             string   // Go method name "ButtonWithTitle"
    Selector         string   // ObjC selector "buttonWithTitle:target:action:"
    ClassName        string   // "Button"
    ReceiverShort    string   // "b_" or "bc"

    // Signature
    IsClassMethod    bool     // vs instance method
    IsConstructor    bool     // Returns instance of class
    ReturnType       string   // Go return type
    ObjCReturnType   string   // Objective-C type

    // Parameters
    ParamsWithTypes  string   // "title string, target objc.IObject"
    ParamNames       string   // "title, target, action"
    Parameters       []ParameterData

    // Documentation
    Abstract         string
    DocURL           string
    Availability     Availability
}
```

### ParameterData

```go
type ParameterData struct {
    Name             string   // "title"
    Type             string   // "string"
    ObjCType         string   // "NSString *"
    IsInterface      bool     // Use I-prefix type
}
```

```go
func generateDarwinKitFiles(...) error {
    // Generate shared files
    generateFile("doc.gen.go", docTemplate, genData)
    generateFile("gen.go", genTemplate, genData)
    if len(functions) > 0 {
        generateFile("functions.gen.go", functionsTemplate, genData)
    }

    // Generate one file per class
    for _, cls := range classes {
        classData := buildClassData(cls, findMethodsForClass(cls))
        filename := classData.FileName
        generateFile(filename, classTemplate, classData)
    }

    return nil
}
```

## Type Mapping

Objective-C to Go type mappings for DarwinKit style:

| Objective-C Type | Go Type | Notes |
|-----------------|---------|-------|
| `NSString *` | `string` | objc handles conversion |
| `NSInteger` | `int` | Platform int |
| `CGFloat` | `float64` | Always 64-bit in modern macOS |
| `BOOL` | `bool` | Direct mapping |
| `id` | `objc.Object` | Generic object |
| `NSObject *` | `objc.Object` | Base object |
| `NSButton *` | `Button` | Concrete type |
| `id<NSButtonProtocol>` | `IButton` | Interface type |
| `SEL` | `objc.Selector` | Selector type |
| `Class` | `objc.Class` | Class object |
| `void *` | `unsafe.Pointer` | Raw pointer |
| `NSRect` | `foundation.Rect` | Struct |
| `NSSize` | `foundation.Size` | Struct |
| `NSPoint` | `foundation.Point` | Struct |

## Naming Conventions

### Class Names

- Strip Objective-C prefix: `NSButton` → `Button`
- Keep camelCase: `NSURLRequest` → `URLRequest`

### Method Names

- Convert selector to Go: `buttonWithTitle:target:action:` → `ButtonWithTitleTargetAction`
- Remove underscores in parameters: `with_arg:` → `WithArg`
- Capitalize first letter of each component

### File Names

- Convert to snake_case: `Button` → `button.gen.go`
- Use lowercase: `URLRequest` → `url_request.gen.go`

### Receiver Names

- Class methods: `{lowercase_first_letter}c` (e.g., `bc` for ButtonClass)
- Instance methods: `{lowercase_first_letter}_` (e.g., `b_` for Button instance)

```go
func stripObjCPrefix(name string) string {
    prefixes := []string{"NS", "CG", "CF", "CA", "CI", "CL", "CM", "CV", "MPS", "MTL"}
    for _, prefix := range prefixes {
        if strings.HasPrefix(name, prefix) {
            return strings.TrimPrefix(name, prefix)
        }
    }
    return name
}
```

```go
	Control
}

	return Button{
		Control: ControlFrom(ptr),
	}
}

func (bc _ButtonClass) ButtonWithTitleTargetAction(title string, target objc.IObject, action objc.Selector) Button {
	rv := objc.Call[Button](bc, objc.Sel("buttonWithTitle:target:action:"), title, target, action)
```

## Benefits

1. **Better organization**: One file per class is easier to navigate
2. **Incremental compilation**: Changes to one class don't recompile all classes
3. **Clearer ownership**: Each class is self-contained
4. **DarwinKit compatibility**: Can potentially replace darwinkit generation
5. **Better IDE support**: Jump-to-definition works better with separate files

## Future Enhancements

1. **Protocol generation**: One file per protocol
2. **Category support**: Extensions to existing classes
3. **Property synthesis**: Generate getter/setter from property declarations
4. **Delegate wrappers**: Type-safe delegate patterns
5. **Block support**: Closure parameters with proper types
6. **Constant generation**: Enums and string constants
